## 4. 营业提成体系（核心）

### 4.1 社员 rank 与固定给（最新版框架）
- **rank 体系 S1~S22**，固定给区间约 **21万~50万円**（含みなし残業/固定残業代）。
- **营业职固定给上限 = S16（40万）**；S17 以上为管理/特殊安排。
- 各 rank 对应"半年昇給指标（税抜）"。

### 4.2 売上定义（税抜）
- **仲介案件 売上 ＝（入金売上 − コスト）**
- **仕入再販 売上 ＝（再販金額 − 仕入金額 − コスト）**

**コスト**包含：紹介料·业务委托料等；登記費用（移転·抵当权）、仲介手数料、印紙代、建物消費税、融資手数料、不動産取得税等。

### 4.3 仕入再販 · 売上计上比例（按转卖速度递减）
- A・B・C 中間省略（无仕入登记）→ **100%** 计上
- 需仕入登记时（自 AB 決済日起算）：
  - 1 个月内再販完 → 100%
  - +3 个月（累计 4 个月）内 → 75%
  - +3 个月（7 个月）内 → 50%
  - +3 个月（10 个月）内 → 25%
  - 再往后 → 0

### 4.4 结算与升降级
- **半期入金ベース**计提成，一年发 2 次（上半期 12月~5月→6/25；下半期 6月~11月→12/25）。
- **昇格**：半期业绩超过下一 rank 指标可申请（最新版限 1 级/半期）；过去业绩累计为负时不予昇給。
- **降格**：不达本 rank 半期昇給指标 100% 则降至对应业绩 rank；**降格最终由社長决裁**。
- 歩合适用对象：至营业次长级。

- **文书保存**：永久 / 10 年 / 7 年 / 5 年 / 3 年分级（定款·登记·契约·会计凭证等对应不同年限）。

## 8. 賃貸保证/管理会社 · 外国人（华人）承接知识（行业通用干货）

面向外国籍（尤其在日/海外华人）客户配租时，各保证/管理会社政策差异极大。**核心比较维度**：

| 维度 | 说明 |
|---|---|
| **国际审查（海外非居住者）** | 可 / 不可——决定海外客户能否直接过审 |
| **紧急联系人** | 「在日中国人可」宽松 / 「必须日籍或永住」较严 / 「担当本人可」 |
| **押金** | 退 / 不退（不退型退房时扣除不返还） |
| **申请年龄** | 多数 18+，部分 17、部分 20+ |
| **首付高低** | 与礼金/押金/AD/月额费相关（0礼0押型首付低） |
| **違約金** | 常见"1 年内退房 1 个月房租、2 年内 1 个月"等，差异大 |
| **重説归属 / AD** | 部分自社重说、部分 AD 高（影响提成 コスト） |

**实务判断顺序（脱敏方法论）**：
1. 客户是**海外非居住 or 在日** → 先筛「国际审查可」的保证会社。
2. 能否提供**在日中国人紧急联系人** → 决定可选池宽窄（要日籍的排除）。
3. **年龄**是否满足（未满 18 找可 17 的）。
4. 预算敏感 → 选 0礼0押/首付低型；在意退款 → 选押金「退」型。
5. 留学生/日语弱 → 避开"日语要求高/留学生需确认"的会社。

> 具体保证会社名称与逐条政策为**第三方行业信息**，本库以方法论形式保留，便于按客户条件匹配；如需可现场按最新一览逐家核对。

**投資マンション（区分）业者**：市场存在多家专营投资用区分マンション的开发/销售商，通常提供**首付计算表**；对接时注意各家审查速度、礼押结构与退房条件。

## 9. 物件·市场知识（泛化，无楼盘名/门牌）

基于自社売主物件结构提炼的**产品与市场规律**（面向海外华人投资/自住客，可配投资贷款）：

**产品线**
- 区分マンション（1 室，投资/自住）
- 一棟マンション/ビル（含店铺混合，收益型）
- 戸建（含庭付平屋、新築戸建）
- 土地（更地 / 古家付 / 持分·私道负担型）
- 一棟民泊（旅館業取得済，NOI 利回り计价）

**价格带**：从数百万円（小型区分/店舗）到数亿円（一棟ビル/都心高单价住宅）。

**利回り分布**
- 都心自住/资产保值型：利回り低（甚至无标注），主打立地与资产价值，常配低利率融资卖点。
- 一棟收益型（多在埼玉·千葉·神奈川周边）：表面利回り可达 7%~15%+，注意区分**表面**与**想定/NOI**利回り、满室 or 部分サブリース。

**区域分布（区/市级）**：东京 23 区（足立·葛飾·杉並·板橋·世田谷·品川·新宿等）、埼玉（川口·狭山·ふじみ野·所沢等）、千葉（市川·松戸·柏等）、神奈川（横滨周边）。

**必须重点告知的风险点（重要事項説明）**
- **心理的瑕疵物件**：如曾发生火災死亡等事故的土地/建物，须充分告知（可能更地渡し）。
- **道路·持分·私道负担**：前面道路事業中、位置指定道路、私道持分/セットバック负担等。
- **旧耐震/新耐震**、大规模修繕予定、古家付現況渡し等状态。

**融资卖点**：面向海外非居住者的投资贷款可对接；对中国客常以中文对应 + 低利率试算切入。
