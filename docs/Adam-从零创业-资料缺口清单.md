## 8 大支柱 · 缺口明细（按创业生死顺序）

### ① 开业·牌照·法务落地 —— 缺口大
**要什么**
- 宅建業免許 申请全流程：知事 / 大臣 的区别、**専任宅建士 5:1 规则**、事務所要件、**営業保証金 1,000万円 or 保証協会加入（弁済業務保証金分担金约 60万）** 的选择与成本、审批周期
- 关联牌照落地要点：**貸金業登録**（融资臂）、**賃貸住宅管理業登録**（管理 200 户以上）、**サブリース＝特定転貸事業者登録**、**民泊（住宅宿泊事業）/ 旅館業**届出、（工事规模大）**建設業許可**
- 会社設立·定款·資本金 的实操要点

**格式**：开业 checklist / 申请要件表 / 成本·周期一览（可 Excel 或文字）
**为什么**：没有牌照与合法主体，一切归零。

---

### ② 仕入·房源调达渠道 —— 生命线
**要什么**
- 房源来源类型与占比：業者間流通、任意売却、相続、競売、オーナーチェンジ、金融机関/弁護士/税理士介绍等
- **仕入判断基准**（利回り下限、立地、耐震、法令上限制、瑕疵筛查）
- **买取资金调达结构**：银行 / ノンバンク、金利区间、LTV、周转周期
- 稳定 pipeline 的维护方式（合作方类型，脱敏）

**格式**：渠道类型表 + 仕入基准表 + 资金结构说明（**去掉具体合作方名称与人名**）
**为什么**：仕入再販模式的命根子，没有稳定房源公司即停摆。

---

### ③ 集客·华人客户获取 —— 生命线 / 核心价值
**要什么**
- 获客渠道与漏斗：微信 / 小红书 / 微博 运营、国内合作/介绍网络、现地セミナー、反響媒体（门户/自社HP）
- 关键指标：来客数、反響率、成約率、**CPA（获客成本）**、客单价
- 商談流程与话术框架（**去客户信息**）、販売図面（マイソク）的构成要素

**格式**：获客渠道表 + 漏斗指标（可给区间/占比，不必真数字）+ 商談流程图 + 图面模板结构（空白）
**为什么**：Adam 模式最值钱的护城河就是"中国客集客力"，也是当前最大空白。

---

### ④ 資金·単位経済·財務模型 —— 决定赚不赚钱
**要什么**
- 一单的经济账：仲介单 / 仕入再販单 各自的**平均売上·成本·毛利**
- 公司层面：开业资金、月度ランニングコスト、**损益分岐点**、仕入资金周转次数
- 简版 PL 结构（比例即可）

**格式**：单笔单位经济表 + 简版损益模型（可用比例/区间，无需真实财报数字）
**为什么**：提成公式只是成本侧，无法判断整体是否盈利。

---

### ⑤ 取引実務·契約テンプレ·決済流程 —— 落地能力
**要什么**
- **売買契約書 / 重要事項説明書** 的结构与要点（空白模板或要点清单）
- 決済フロー：司法書士手配、融資実行、登記、精算
- 賃貸全流程：申込 → 審査 → 契約 → 鍵渡し 的 checklist
- 案件チェックリスト（売買 / 賃貸各一套）

**格式**：空白模板 / 流程图 / checklist（**务必去除任何真实当事人信息**）
**为什么**：知道"有哪些审批"不等于"能跑完一单"。

---

### ⑥ 外国人向け融資スキーム —— 最强护城河
**要什么**
- 面向**海外非居住者 / 在日外国人**的贷款方案：可对接的金融机関类型、审查基准、必要书类
- **フラット35** 对外国人的条件、自社审查逻辑、LTV / 金利 / 期限
- 非居住者融资的可行边界与常见卡点

**格式**：融资方案对比表 + 审查基准清单（**去掉具体银行经办与客户信息**，保留机构类型与条件）
**为什么**：海外客几乎无法自行搞定融资，这是最难复制的价值点。

---

### ⑦ 税務·投資スキーム —— 提升客户价值
**要什么**
- 投资客税务包：減価償却、譲渡所得（短期/長期）、消費税、不動産取得税、固定資産税
- 法人スキーム、**海外投资家的源泉徴収/申告**、匿名組合等
- 给客户用的**试算表结构**（空白）

**格式**：税目一览 + スキーム说明 + 空白试算表
**为什么**：税务筹划是打动投资客的关键卖点。

---

### ⑧ 市場データ·競合分析 —— 做得好不好
**要什么**
- 市场基准：路線価 / 地価公示、レインズ成約事例、賃料相場、空室率、人口動態、エリア別需给
- 竞合：大手（三井/住友/東急等）+ 面向华人同业 + 投资平台（楽待/健美家等）的定位对比

**格式**：可后期用公开数据补，你若有内部市调/竞品表更好
**为什么**：没有基准就无法判断定价与利回り的竞争力。
