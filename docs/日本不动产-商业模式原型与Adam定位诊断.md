# 日本不动产 · 商业模式原型拆解 与 Adam 定位诊断

> 目的：回答"**从零在日本做地产，该走哪条路、护城河在哪**"。
> 本文不依赖任何内部敏感资料，为行业结构分析 + 基于脱敏知识库的定位诊断。

---

## 0. 先理解一个结构性前提（决定一切打法）

日本不动产业有三条**法定/行业结构**，新进入者必须先看懂：

| 结构 | 内容 | 战略含义 |
|---|---|---|
| **宅建業免許制** | 无免许不得从事売買·仲介 | 牌照是硬门槛，但**不是护城河**（谁都能考） |
| **レインズ（指定流通機構）登录义务** | 受托物件须登录到全国共享网 | **房源信息高度共享 → 靠"独家房源信息"很难长期取胜** |
| **仲介手数料法定上限** | 売買约「成交价3%+6万」、賃貸约「租金1个月」 | 价格战空间小，**大家收费趋同 → 差异在别处** |

### 由此推出的核心结论

> **在日本，房源信息是公共品，客户才是稀缺品。**
> 既然人人都能查到同样的房源、收同样的手续费，那么**胜负手在"谁能接触到客户、谁能被客户信任、谁能帮客户解决他自己解决不了的事"。**

这就是为什么"**面向华人客户**"这个定位在结构上是成立的——它同时解决了三件事：
1. **客户接触**（中文圈获客，日本本土公司够不着）
2. **信任**（语言 + 文化 + 同乡networks）
3. **解决不了的事**（外国人融资、签证、税务、远程管理）

## 1. 六大商业模式原型

| # | 原型 | 收益来源 | 资本要求 | 护城河 | 主要风险 | 从零创业难度 |
|---|---|---|---|---|---|---|
| ① | **賃貸保有型**（ストック） | 租金 + 资产增值 | 极大 | 土地（不可再生）、低息调达 | 利率上升、空室 | ★★★★★ |
| ② | **開発·分譲型** | 分譲售价 − 用地·建筑成本 | 大 | 用地情报网、品牌、施工力 | 库存滞留、市况反转 | ★★★★ |
| ③ | **流通·仲介型**（フロー） | 仲介手数料 | **小** | **集客力**、担当者信任 | 市况连动、人依赖 | **★** |
| ④ | **買取再販型** | 再販 − 仕入 − 改装 − 诸费 | 中~大 | 仕入渠道、改装成本控制、**周转率** | **库存滞留**、利率 | ★★★ |
| ⑤ | **賃貸管理·PM型**（リカーリング） | 管理料(租金3~5%)、原状回復、更新料、保险代理 | 小~中 | **管理户数**（切换成本高）、业主关系 | 低（最稳） | ★★ |
| ⑥ | **AM·ファンド型** | AM fee（AUM×%）、成功报酬 | 小（但需信用/实绩） | 投资人网络、track record | 募资失败 | ★★★★ |

### 关键洞察

- **①②是"资本游戏"** — 没有巨额资本或历史资产（如 Hulic 继承的银行地块），从零无法进入。
- **③是唯一的低资本入口** — 但也最容易被复制，必须靠**集客力**建立差异。
- **④是"周转游戏"** — 赚的不是差价，是**周转速度**。库存压住就亏死（利息+持有成本）。
- **⑤是"复利游戏"** — 单笔小、但**收入可累积且极稳**，是穿越周期的压舱石。
- **⑥需要时间积累信用**，无法速成。

## 2. Adam 现有模式定位

Adam 集团实际横跨 **③④⑤ + 融资 + 工事**：

```
③流通(仲介)  ←本体，面向华人客户的売買·賃貸
④買取再販    ←开发主体，仕入→再販
⑤賃貸管理    ←资产管理主体，含原状回復·工事·民泊
＋融资        ←贷金业主体，非居住者贷款安排
＋工事        ←改装·解体，内部消化成本
```

### 这个组合的三个优点

1. **现金流互补**：③提供即期现金流，⑤提供稳定复利，④提供利润弹性
2. **成本内部化**：改装/管理/融资都在集团内 → 提升利润率，且能对客户"一站式"
3. **客户 LTV 拉长**：一个华人客户可以在集团内完成"买 → 贷 → 装 → 管 → 卖"全生命周期

### 从提成设计反推的经营智慧

知识库里那条**仕入再販计上比例递减规则**（1个月内100% → 4个月75% → 7个月50% → 10个月25% → 之后0）值得单独点出：

> 这是把**原型④的核心风险（库存滞留）直接写进了个人薪酬**。
> 营业员不是"卖掉就有钱"，而是"**卖得快才有钱**"。
> 这是一个把公司层面的资产负债表风险，翻译成个人层面激励的精巧设计。

## 3. 从零创业 · 建议路径（资本由轻到重）

不要一上来就复制 Adam 的全链条——那是**积累出来的结果**，不是起点。

### Phase 1：③流通型切入（0~12个月）
- **要什么**：宅建業免許（保証協会加入约60万起步，比営業保証金1,000万轻得多）+ 事務所 + 専任宅建士
- **做什么**：中文圈获客 → 賃貸仲介起步（成交快、现金回收快、试错成本低）→ 逐步做売買
- **目标**：**验证集客模型**，跑通 CPA 与成約率，活下来

### Phase 2：⑤管理型叠加（12~24个月）
- 把成交客户的物件转为**管理受托**（管理料 + 原状回復 + 保险代理）
- **目标**：建立**不依赖成交的经常性收入**，抗周期

### Phase 3：④買取再販（24个月+，需资本）
- 用前两阶段积累的**资本 + 仕入渠道 + 客户池**做小额买取再販
- **关键**：先建"卖得掉的确定性"（客户池），再买货 —— **反过来做会死在库存上**

### Phase 4：融资安排 / ⑥AM（长期）
- 非居住者融资 arrange 能力 → 最强护城河
- 有实绩后可做小型基金/共同投资

### ⚠️ 路径的核心逻辑

> **先有客户，再有货；先有周转，再有规模；先有现金流，再有资产。**
> Adam 现在的样子是终局，不是起点。

## 4. 真正的护城河在哪（排序）

| 排名 | 护城河 | 可复制性 | 说明 |
|---|---|---|---|
| 🥇 | **华人客户获取能力** | 低 | 中文圈渠道、口碑网络、文化信任——日本本土公司做不了，新进入者要从零建 |
| 🥈 | **外国人/非居住者融资安排力** | 极低 | 海外客几乎无法自行搞定；需要与金融机构的长期关系 + know-how |
| 🥉 | **全链条一站式** | 中 | 买贷装管卖闭环，提升 LTV 与切换成本 |
| 4 | **管理户数积累** | 低（但慢） | 时间的朋友，越久越难被撬 |
| 5 | **仕入渠道** | 中 | 关系型，可建但需时间 |
| — | 房源信息 | **高（不是护城河）** | レインズ 使其成为公共品 |

## 5. 对照 Hulic 的启示（何者可学、何者不可学）

| ❌ 不可复制 | ✅ 可迁移 |
|---|---|
| 银行继承的历史成本土地 | **选择与集中**：死守特定客群 × 特定区域 × 特定产品 |
| 银行系超低融资成本 | **重资产轻人力**：执行外包，核心只做判断与客户关系 |
| 数十年都心地块积累 | **买潜在价值而非市价收益**（改装/用途变更/瑕疵处理后的价值提升） |
| 零利率时代杠杆红利 | **资本效率导向**：看周转率与 ROE，不只看成交额 |
| | **流动性纪律**：只碰好卖、好融资的资产 |
