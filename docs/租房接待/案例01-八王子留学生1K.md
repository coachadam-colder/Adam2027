# 案例 01 · 八王子留学生 1K（脱敏记录）

> 人物代号：**学生 A**（客户）、**担当 B**（营业一部，主攻）、**介绍人 C**（前线）。
> 已去除：姓名、手机号、微信名、学校全名、楼盘名、门牌号、员工名片。

| 项目 | 内容 |
|---|---|
| 客户类型 | 留学生，专门学校在读，单身 |
| 来源 | 介绍人 C 在微信群温交接给担当 B |

| 预计居住 | 约 2 年以上（到毕业前） |

## 二、需求

| 项目 | 希望 |
|---|---|

| 区域 | 八王子一带，步行到八王子站 8 分钟以内 |
| 户型 | 1R 或 1K，一人住 |

## 四、做得好的地方

1. **温交接**：介绍人当面在群里介绍担当，学生信任顺利转移。这正是"前线 + 主攻"小组分工里最关键的一步。
2. **先讲时期规律，管理预期**：学生知道现在找 2 月下旬入住的房子选择少，不会急躁，也不会误以为中介不努力。
3. **只推留学生可入住房源**，并鼓励学生把网上看中的户型发过来，按户型找同类房源。
4. **用"哪里不满意"调整方向**：推荐后请学生逐套点评，第一轮就找到了中意的房型。
5. **对"事故物件"疑问认真确认**：向管理公司核实，并给出合理解释（北向 → 改户型），消除顾虑。
6. **问居住期限**：住到毕业约 2 年多，更新料、短期解约违约金都要纳入比较。
7. **看完房立即暂留**，给家人商量的时间，同时设定次日答复的期限。

## 五、可以改进的地方

| 问题 | 建议 |
|---|---|
| **12 月起租 vs 2–3 月搬家**：若提前起租，学生要多付约 2–3 个月房租，金额不小 | 先算出多付金额告诉学生和家长；再向管理公司**谈延后起租日或免租期（フリーレント）**。北向、装修中的房间不易租，房东往往愿意让步 |
| **保证会社费用没讲清频率**：学生问了两次"一次性还是每年" | 按"初次保证费 + 每年（或每月）续费 + 金额"书面讲清；不要只说"2 万以内" |
| **在群里要手机号**：学生把号码发在了群里 | 改为私信索取；群里只谈房源 |
| **"事故物件"只做了口头答复** | 保留管理公司的书面或邮件回复；签约时以重要事項説明为准 |
| **想看 303，实际看的是同楼另一间** | 说明清楚看的是哪间、和 303 的差异（朝向、户型、楼层、装修完成后的状态），避免误会 |
| **家长参与决策** | 准备一份中文费用明细（入住费用、月付、两年总花费），方便学生转给父母 |
| **旺季在即**：八王子学生多，2–3 月竞争激烈 | 提前请学生备齐申込审查资料，一旦决定当天就能提交 |

## 六、下一步行动

1. 次日跟进学生答复。
2. 若决定申込：确认起租日能否延后或免租期 → 出费用明细（中文版给家长）→ 收集审查资料 → 提交申込。
3. 若不定：记下不满意的原因，继续推荐，并在 1–2 月重点盯 2 月下旬可入住的新房源。
4. 签约后：重要事項説明、入住前拍照；交钥匙后一周回访。
5. 成交后做满意度问卷，并请学生介绍同学（介绍人记录在台账）。

## 七、可复用话术

**讲时期规律**
> 日本租房一般要提前 1–2 个月通知解约，所以现在网上挂的房子，最晚大概 1 月中下旬能入住。您 2 月下旬搬家，合适的房源会在 12 月到 1 月陆续出来，我会一直帮您盯着，有合适的第一时间发您。

**回答"是不是事故物件"**
> 我已经向管理公司确认过，这间不是事故物件。价格相同的原因是朝北，房东把它改成了 1K。签约前的重要事項説明里也会写明，您可以放心。

**起租日早于搬家日**
> 这间要求 12 月内起租，如果按 12 月起租，到 2 月搬家要多付大约 X 个月房租，合计约 X 万日元。我先帮您和管理公司谈一下，看能不能把起租日往后推，或者给一个月免租。

**保证会社费用**
> 保证会社的费用分两部分：签约时一次性付 X 日元；之后每年（或每月）续费 X 日元。具体以这套房子的保证会社条件为准。
