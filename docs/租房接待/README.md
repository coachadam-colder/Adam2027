## 二、标准接待流程

```
介绍人温交接 → 首次问需求 → 讲清市场时期规律 → 推荐房源 → 客户反馈与追问
  → 确认告知事項/费用 → 预约看房 → 现场看房 → 暂留房间 → 申込・审查 → 签约(重説) → 交钥匙 → 入住后跟进
```

| 阶段 | 要点 |
|---|---|
| 温交接 | 介绍人在群里当面介绍担当，说明担当负责区域和经验。客户信任要"交过去"，而不是甩联系方式 |
| 首次问需求 | 先问搬家时间、预算（**是否含管理费**）、区域、户型、居住期限，再问细节偏好 |
| 讲时期规律 | 普通租约需提前 1–2 个月通知解约，所以**大约只能找到 1–2 个月后可入住的房子**。太早找，选择少 |
| 推荐房源 | 只推**留学生可入住**的房源；请客户说明每套"哪里不满意"，据此调整方向 |
| 客户追问 | 当天回复；不确定的说"回事务所确认后答复"，并**给出时间** |
| 告知事項 | 客户问"是不是事故物件"时，向管理公司确认，**保留书面回复**；签约时以重要事項説明为准 |
| 费用 | 用书面明细回答，讲清每项是**一次性、每月还是每年** |
| 看房 | 让客户给两个时间段；钥匙预约需时间，提前说明 |
| 暂留 | 看完房向管理公司申请暂留，并告诉客户**最晚什么时候答复** |
| 申込・审查 | 提前准备审查资料（见下方清单），避免在旺季因资料慢而丢房 |

## 三、首次问需求清单（复制使用）

- 预计搬家日期（范围）
- 月租预算：上限、理想价位，**是否含管理费/共益费**
- 入住费用上限（礼金、押金、中介费等合计）
- 区域、最远步行分钟数
- 户型、面积
- 楼层、朝向、电梯、结构（RC 等）、角部屋、隔音、空调、阳台
- 学校或公司位置
- **预计住多久**（影响更新料、短期解约违约金是否划算）
- 谁付款（本人/父母），是否需要发中文费用说明给家人
- 有无日本籍紧急联系人、在留期限到何时

## 四、费用说明清单（每套房都要讲清）

| 费用 | 要讲清 |
|---|---|
| 月租 + 管理费/共益费 | 合计多少 |
| 礼金、押金 | 押金退租时怎么扣 |
| 中介费 | 多少 |
| **保证会社** | 初次多少；之后**每年**续费还是**每月**收，金额多少 |
| 火灾保险 | 期限（常见两年） |
| 钥匙更换、清扫、消毒等 | 哪些可选 |
| 更新料 | 有无、金额（住两年以上就会遇到） |
| 短期解约违约金 | 几个月内退租要付多少 |
| **起租日** | 从哪天开始付房租 |

## 五、申込审查资料（留学生常见，以管理公司和保证会社要求为准）

- 在留卡（正反面）
- 学生证或在学证明、入学许可
- 护照
- 紧急联系人信息（有的保证会社要求日本籍或在日居住者）
- 父母作为连带保证人时的相关资料（视保证会社）
- 存款或汇款证明（视情况）

## 六、要守住的规则

- **不要在群里要手机号**，请客户私信发送；聊天记录里的联系方式不要转存到共享文档
- 告知事項以管理公司书面回复和重要事項説明为准，**不要凭口头印象断定"不是事故物件"**
- 不承诺审查一定通过
- 签约前由宅建士做重要事項説明；入住前提醒客户拍照留存
