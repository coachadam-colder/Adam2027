# 中日跨文化选题库

## 怎么用这份清单

不要直接把某一行当选题——它们是**认知差原料**。每一条都要先过 Step 0 的三件套（认知差 / 情绪 / 画面）再进生产线。

一个好选题的检验标准：**中国观众和日本观众看完，会得出不同的"原来如此"**。两边都有话说，评论区才会热。

---

## 一、按情绪分类的选题池

情绪决定传播方式：委屈引共鸣，惊讶引转发，好笑引点赞，温暖引关注。

### 委屈 / 孤独（共鸣最强，适合涨粉）

- 日语学了三年，还是没有能约出来吃饭的日本人
- 「また今度」当真了，等了三个月
- 在小组作业里永远是最后被组队的那个
- 打工时被夸「日本語上手ですね」，后来才明白那不是夸奖
- 群里日本同学在聊天，插不进去话
- 春节一个人在出租屋煮饺子

### 惊讶 / 反差（转发最强，适合破圈）

- 日本朋友第一次进海底捞，被免费美甲和拉面表演震住
- 日本人看到中国的移动支付 / 高铁 / 外卖速度
- 中国人发现日本还在用现金、传真、印章
- 日本人以为的中国 vs 现在的中国（用真实照片对比）
- 中国人以为的日本 vs 住下来的日本（房租、通勤、加班）
- 日本便利店的关东煮 vs 中国便利店的关东煮

### 好笑 / 尴尬（完播最强）

- 敬语用错的社死现场
- 中文和日语同形异义词闹的笑话（「手紙」「大丈夫」「勉強」「愛人」）
- 日本朋友第一次说中文的口音
- 点餐时把「大盛り」听成别的
- 在日本便利店说「谢谢」被回「ありがとうございます」

### 温暖 / 治愈（关注转化最强）

- 打工店长在你生病时留了饭
- 日本同学偷偷学了一句中文来打招呼
- 房东阿姨送的第一份年货
- 毕业时日本朋友说的那句话

## 二、高价值认知差清单

这些是**观众真的不知道、而且知道了有用**的点，直接构成 Education 层：

| 认知差 | 大家以为 | 其实 |
|---|---|---|
| 邀约方式 | 「今度ご飯行こう」是邀请 | 是客套。要给具体日期才算真邀请 |
| 「行けたら行く」 | 可能会来 | 基本不会来 |
| 「考えておきます」 | 在考虑 | 已经拒绝了 |
| 「日本語上手ですね」 | 夸奖 | 也可能是"你还是外人"的信号 |
| 沉默 | 冷淡 | 是在给对方留余地 |
| 本音と建前 | 虚伪 | 是降低摩擦的社交润滑 |
| 割り勘 | 小气 | 是"不欠人情"的平等意识 |
| 中国人主动性 | 中国人不想交日本朋友 | 是不知道怎么开口，怕给人添麻烦 |
| 日本人主动性 | 日本人排外 | 日本人也不知道怎么开口，怕说错话冒犯 |
| 微信 vs LINE | 只是软件不同 | 加好友的社交含义不同（LINE 更私人） |

**最有价值的一条**：*双方都想接近，双方都以为对方不想。* 这是整个账号的母题，值得反复用不同故事讲。

## 三、普世话题 ×「日本作为论据」（天花板最高的一类）

前面两节的选题，日本都是**主题**——受众上限是"对日本感兴趣的人"。
这一节相反：选一个**所有中文观众都关心的话题**，用你的在日经历当**独家论据**。受众上限直接放大到全体中文观众，而你依然是最有资格说这话的人。

**能和在日经历天然咬合的普世话题：**

| 普世话题 | 日本经历提供的论据 | 可以命名的价值观 |
|---|---|---|
| 规则意识 | 严到不近人情，但排队没人插、承诺会兑现 | 规则是陌生人之间成本最低的信任 |
| 人际距离 | 不过问隐私、不轻易越界 | 客气不是冷漠，是给对方留退路 |
| 服务与尊严 | 便利店店员和公司社长同样被称"さん" | 职业不分贵贱不是口号，是可以被制度化的 |
| 努力与回报 | 论资排辈 vs 中国的快速晋升 | 稳定的代价和流动的代价，各有各的账 |
| 什么算体面 | 不炫耀、不比较的日常 | 体面是不给别人压力 |
| 时间观念 | 电车晚 1 分钟要道歉 | 守时是把别人的时间当资产 |
| 匠人与重复 | 一辈子做一件事的店 | 重复不等于停滞 |
| 老去这件事 | 高龄社会的日常图景 | 一个社会怎么对待老人，就是它的底色 |

**写这类选题的固定结构**：

```
普世现象（所有人都有感）
    ↓
一个具体的个人故事 / 一条真实评论
    ↓
给现象命名（认同型价值层，可转发的那句）
    ↓  70% 处
「在日本待久了我更确定这一点……」  ← 日本登场，作为证据
    ↓
金句 + 讲故事型提问
```

**自检**：把所有提到日本的句子删掉，内容还成立吗？成立才算这一类。

**主力配比建议**：这类占 40%，中日垂类占 45%，转化款 15%。全做这类会失去差异化，全不做会卡在小盘子里。

## 四、内容矩阵：别只做一种

一个健康的账号需要三类内容按比例混合：

- **涨粉款（50%）**：街头采访、反差实验。冲播放，吸新观众。
- **人设款（35%）**：故事复盘、日常。让路人变粉丝，记住你是谁。
- **转化款（15%）**：交流会招募、社群、课程。别超过这个比例。

**系列化**：给重复的形式起个固定名字，比如「日本人に聞いてみたシリーズ」「日本人の彼女に見せてみた」。观众认系列不认单条，第 3 条起会开始有人追更。

## 五、雷区（必须避开）

这不是保守，是账号存活问题。踩了以下任何一条，轻则限流，重则封号，而且引来的流量全是有毒流量——涨的粉留不住，评论区永远在吵架。

**绝对不碰**：

- 政治制度、领土争议、历史遗留问题
- 民族优劣比较、"哪国人更好"
- 地图、国旗相关的任何视觉素材
- 引战式提问（「中国と日本、どっちが〜？」）
- 拿单个坏例子代表整个国家的人

**谨慎处理**：

- 收入、房价、物价对比 → 容易滑向优越感，务必以"个人体验"陈述，不下结论
- 职场吐槽 → 别指名道姓，别拍能认出来的店面和工牌
- 恋爱话题 → 避免"日本女生都…""中国男生都…"这类全称判断

**表达上的三条铁律**：

1. **只讲"我遇到的"，不讲"他们都是"**。个人经历没人能反驳，全称判断人人都能反驳。
2. **不下优劣结论，只呈现差异**。「違う」而不是「おかしい」。
3. **被误解的一方，让他自己说话**。想说日本人不排外，就去拍日本人说话，别自己替他们下结论。

## 六、素材长期积累

爆款不是想出来的，是攒出来的。建议持续记录：

- 每次被日语"卡住"的瞬间（这是最真实的痛点素材）
- 每次日本朋友的意外反应（原话记下来）
- 评论区里被追问最多的问题 → 直接做成下一条视频，这类命中率最高
- 私信里重复出现的困惑 → 说明是普遍痛点

**评论区是最好的选题库**。一条视频下面出现三次以上的同一个问题，就是下一条视频的选题，几乎不会翻车。
