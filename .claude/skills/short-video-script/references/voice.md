# 声音档案（账号主的个人风格）

这份档案从账号主实际发布过的脚本里提炼。**生成任何脚本前先读这里**——写得像不像他，比写得好不好更重要。观众关注的是一个具体的人，不是一个会写爆款的机器。

样本来源见 `examples/`，每收到新素材就更新这里。

---

## 核心气质：诚实 > 煽情

这是他所有内容的底层，也是最不能动的东西。

两个已验证样本都在**主动拆掉自己本可以拿到的光环**：

- 《规则》那条：明明可以站在道德高地训人，但他把判断权让给了评论区——"绝大多数人说的是同一句话"，结论是别人得出的，不是他喊的。
- 《重新开始》那条：明明可以拍成励志故事，但他先说"还是没站稳""不是什么成功的故事"。

**这是他的护城河。** 观众对被说教和被煽情的免疫力极强，但对"这人肯说自己还不行"几乎没有防御。任何把他的诚实翻译成正能量的改写，都是在拆他的地基。

## 句子层面的特征

1. **短句，一句一个意思。** 几乎不用"而且 / 然而 / 因此"，靠句号推进。
2. **破折号做停顿和重音**：`说实话——五个月过去了，我还没站稳。`
3. **口语标记高频**：`说实话` `你发现没有` `有条评论我看完愣了很久` `我愣在那儿`
4. **先自曝，再讲道理。** 观点永远跟在一个自己的窘境后面，从不空降结论。
5. **结论克制，留余地。** 用"越来越多人""至少在我这儿"，不用"所有人""这代人都"。
6. **结尾是邀请，不是号召**：`我们一起往前走` / `说给我听`，不是`快来关注`。
7. **不用感叹号、不用夸张形容词、不用网络热词。**

## 改写禁区

生成脚本时**不许**做这些事，做了就不是他了：

| 禁止 | 原因 |
|---|---|
| 加感叹号、"太震撼了""泪目""破防" | 他的稿子里一个都没有 |
| 把"还没站稳"改成"正在成长" | 这是把诚实翻译成正能量，等于删掉他唯一不可替代的东西 |
| 替他喊口号（"加油""冲""你也可以"） | 他从不号召，只邀请 |
| "家人们""宝子们"等直播话术 | 与气质完全冲突 |
| 编造细节（具体地点、对话、数字） | 真实细节是护城河。缺细节就问他，别自己填 |
| 把个案推成全称判断 | 见 `examples/rules.md` 末尾的风险提醒 |

## 反复出现的母题

这些是他真正在讲的东西，新素材大多能归到其中一个：

- **规则与信任** —— 规则是陌生人之间成本最低的信任
- **重新开始 / 悬空期** —— 难的不是决定，是勇气用完之后
- **诚实地承认还没成功** —— 反成功学
- **在异乡的具体麻烦** —— 手续、表格、听不懂的电话；不是浪漫，是琐碎
- **双方都想靠近，双方都以为对方不想** —— 中日之间的核心误会
- **务实 vs 投机** —— "聪明"在他这儿已经不算好话了。他反对的是走捷径、投机取巧，主张踏实做事。**说这个母题时必须带上自己**（"我自己也是"），一旦变成站在外面评判同胞，就会翻车
- **一个人的力量很单薄** —— "无论你是谁，身家多少，个人的能力都很单薄。"所以要能互相帮，要有比自己更大的东西托着。这是他价值观的底座，其他母题大多从这里长出来
- **不同人生阶段，"努力"的形状不一样** —— 学生的努力是深度，30 多岁的努力是同时端着好几个碗一个都不能摔。这条是"悬空期"的成年版，共鸣人群极大

## 他的身份坐标（写脚本时的可信度来源）

- 30 多岁，为日本籍女友只身来东京，目前七八个月
- 不是留学生——不能全职学语言，要同时找工作、了解日本市场、开发资源、养家
- N2 差十分未过，12 月再考
- 在办日中语言交流会（已第三期），参加者以留学生和对中国文化感兴趣的日本人为主
- 两家父母已在四国见过面

**这个坐标本身就是内容的护城河**：讲"重新开始"，比他年轻的没他的处境，比他稳的没他的落差。写脚本时要让这个身份出现在该出现的地方——它是让同样的话从他嘴里说出来更有分量的原因。

**用法**：新素材进来时，先看它能挂到哪个母题上。挂得上 → 它是系列的一集，天然有累积效应；挂不上 → 要么是新母题（值得记下来），要么这个选题跟这个账号没关系。
