# 发布包装

同一条成片，换个标题和封面，播放量能差一个量级。这一步的性价比高于任何剪辑技巧。

---

## 1. 标题（投稿文案）

标题不是内容简介，是**第二个钩子**。用户在推荐流里先看到画面，再看到标题，两者要形成合力而不是重复。

**三种可靠写法**：

| 写法 | 例子 | 适用 |
|---|---|---|
| 补充信息（画面没说的） | 「3人目の答えで泣きそうになりました」 | 采访、故事 |
| 制造站队 | 「これ、日本人からしたらどう思う？」 | 认知差、对比 |
| 承认自己的立场 | 「留学3年目のリアルです」 | 情感、复盘 |

**避免**：
- 和屏幕上的字一模一样（浪费一次触达机会）
- 「見てください」「いいねお願いします」（乞求式文案压低分发）
- 超长文案（前 20 字以外的内容在推荐流里会被折叠，重点必须放最前）

## 2. 封面 / 首帧文字

- 首帧就是封面。剪辑时把最有信息量的一帧放在第 0 秒。
- 封面文字 **8–12 个字**，字号占屏宽 70% 以上，高对比色（白字黑描边最稳）。
- 主页看的是九宫格：**同一系列用统一的字体位置和配色**，观众滑到主页时一眼能看出"这是一个系列"，关注率会明显提升。

## 3. 话题标签

- **总数 3–5 个**。堆到十几个会稀释标签权重，看起来也像营销号。
- 结构：**1 个大词 + 2 个中词 + 1–2 个精准词**

例：
```
#日本留学 #中国人留学生 #日中交流 #留学生あるある
```

- 双语受众可以中日各放一半，但别中英日混堆。
- 有系列名就把系列名做成固定标签，方便观众顺藤摸瓜看完整个系列。

## 4. 置顶评论（最被低估的一招）

**发布后立刻自己评论一条并置顶。** 作用有三个：

1. 补充视频里没说完的信息（延长停留）
2. 抛出第二个问题，给评论区一个明确的话题（不然大家不知道说什么）
3. 视频有争议时先给出你的立场，避免评论区跑偏

写法：
> 「補足：この動画は"日本人が冷たい"って話じゃなくて、"お互い声をかけづらい"って話です。あなたはどっち側の経験がありますか？」

## 5. 回评策略

**发布后 1 小时内的互动权重最高**，这段时间尽量守着回评论。

- 优先回**有内容的长评论**，不要只回"❤️"
- 回复用**反问**结尾，把一条评论变成一串对话——一条 5 层楼的对话，算法上抵得过好几十个赞
- 遇到攻击性评论：不吵、不删（删了掉互动），回一句中性的话或直接忽略。**永远不要在评论区和人辩论国别问题**

## 6. 发布时间

面向在日观众，按日本时间：

- **首选 21:00–23:00**（通勤结束、睡前刷手机的高峰）
- 次选 **12:00–13:00**（午休）
- 周五、周六晚上的流量池最大，但竞争也最激烈——内容有把握时用，日常内容放平日更好

## 7. 频率与系列

- **每周 3–5 条**是个人号能长期扛住的节奏。断更两周基本要重新养号。
- 稳定的形式 > 每条都创新。观众需要预期："这个号每次都会问日本人一个尖锐的问题"。
- 数据好的选题**一定要拍第二条**。一条爆了不追，是最大的浪费——同一个题换个受访者、换个角度，第二条往往比第一条更好。

## 8. 数据复盘（每周一次）

只看四个数：

| 数据 | 说明什么 | 怎么改 |
|---|---|---|
| 3 秒留存 < 50% | 钩子废了 | 换钩子类型，重剪前 3 秒 |
| 完播率 < 30% | 中段拖沓 | 砍掉铺垫，加快切换，缩短时长 |
| 评论 / 播放 < 0.5% | 没给行动理由 | 结尾换成必须站队的问题 |
| 关注 / 播放 低 | 没有人设 | 增加故事类内容，减少纯知识 |

**只改一个变量**。同时改钩子和时长，数据变了你也不知道是哪个起的作用。
