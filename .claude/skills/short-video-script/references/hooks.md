# 钩子库（前 3 秒）

钩子的本质只有一个：**制造信息缺口**。观众脑子里必须冒出一个未闭合的问号，手指才会停。

判断一个钩子好不好，只问一句：**看完这句话，观众心里有没有"为什么？/ 然后呢？/ 真的假的？"**
没有 → 重写。三条都没有 → 换选题。

## 1. 反常识断言

否定一个大家默认为真的前提。观众必须听下去才能确认自己是不是错了。

- 「中国人留学生の一番の壁は、日本語じゃない。」
- 「日本語がうまくなるほど、日本人の友達が減りました。」
- 「"すごいですね"は、褒め言葉じゃないかもしれない。」
- 「日本に住んで一番びっくりしたのは、実は食べ物じゃなかった。」

**句式**：「一番○○なのは、△△じゃない。」／「○○ほど、△△になる。」

**注意**：断言必须在视频里被真正解释清楚，否则是标题党，完播率上去了但评论区会骂。

## 2. 第三方视角 / 借嘴说话

自己说自己好没人信，让别人说。街头采访素材天然适配这类钩子。

- 「日本人に聞いてみた。"中国人って怖い？"」
- 「日本人100人に聞いた、中国のイメージ。1位が意外すぎた。」
- 「日本人の彼女に、中国のコンビニを見せてみた。」
- 「日本人の友達に"中国語で一番好きな言葉"を聞いたら、泣きそうになった。」

**为什么强**：观众想验证"日本人到底怎么想"，这是双边受众都关心的问题。日本人想看自己被怎么代表，中国人想看自己被怎么看待——一条视频吃两拨流量。

## 3. 未完成的故事

只给前半句，把结果扣住。最古老也最有效。

- 「日本人の彼女に、中国の火鍋を食べさせた結果…」
- 「初めて日本人の家に招待されて、やらかしました。」
- 「バイト先の店長に言われた一言が、今も忘れられない。」
- 「日本語学校の先生に"もう来なくていい"と言われた日の話。」

**关键**：省略号后面的东西必须真的值得等。扣一个平庸的结果，比不扣还伤——观众会记住"这号骗人"。

## 4. 数字冲击

具体数字比形容词可信一百倍。

- 「日本に3年住んで、日本人の友達は0人でした。」
- 「日本語能力試験N1に受かっても、居酒屋の注文ができませんでした。」
- 「30回誘って、1回だけOKをもらえた話。」
- 「留学費用、月8万円でどう生きるか。」

**要点**：用零头和奇数（3年、8万、47回），整数听起来像编的。

## 5. 身份点名

直接喊出目标观众，让对的人停下来。

- 「日本語学校に通ってる人、これ知らないと損する。」
- 「日本で就活する留学生、この一言だけは言っちゃダメ。」
- 「外国人の友達がいる日本人、聞いてほしい。」
- 「中国人の同僚がいる人へ。」

**注意**：会牺牲一部分泛流量，换来极高的精准互动。适合做转化（活动招募、社群导流），不适合冲播放。

## 6. 从高潮切入

不铺垫，直接把视频最好的一秒放在最前面，然后倒回去讲。

- 开场就是女朋友被辣到跳起来的画面 → 切黑 → 「3分前に戻ります。」
- 开场就是被采访日本人愣住的表情 → 「この質問、聞いた瞬間に空気が変わった。」

**做法**：剪辑时把 20–35 秒区间里最强的 1.5 秒复制到最前面。零成本，几乎必涨完播。

## 7. 自曝失败

示弱降低防备，观众爱看别人出丑，也爱看真诚。

- 「日本人に"日本語上手ですね"って言われて、喜んでた自分が恥ずかしい。」
- 「"また今度"を本気にして、3ヶ月待ってました。」
- 「敬語を間違えて、バイトをクビになりかけた。」

**为什么强**：这类钩子几乎不会引战，评论区大概率是安慰和"我也犯过"，互动质量高。

## 8. 误解澄清 / 禁忌试探

把大家心里想但不好意思问的话说出来。

- 「聞きにくいことを、日本人に直接聞いてみた。」
- 「中国人がドタキャンしないって、知ってましたか？」
- 「"中国人はうるさい"と言われたので、本人に聞いてみた。」

**红线**：只碰生活文化层面的误解。政治、历史、领土、民族优劣一律不碰（详见 `topics.md` 雷区一节）——这类题的流量是有毒流量，涨的粉留不住，账号还会被限。

## 9. 对比并置

两个画面/两句话直接撞在一起，观众自己得出结论。

- 「中国の大学の寮 vs 日本の大学の寮」
- 「中国人が思う"日本人"、日本人が思う"日本人"。」
- 「日本語の"大丈夫"、中国語の"没事"、実は全然違う。」

**优势**：不需要口才，画面自己会说话，适合口播不自信的创作者。

## 10. 直接提问

最简单，也最容易写废。只有当问题本身足够反常时才成立。

- ❌「日本の文化についてどう思いますか？」（太空）
- ✅「日本人はなんで"行けたら行く"って言うの？」（具体、有痛点）
- ✅「"考えておきます"って、断ってますよね？」

## 改写练习

写不出钩子时，先把平淡的那句写下来，再照下面的方向拧一下：

| 平淡版 | 钩子版 | 用了什么 |
|---|---|---|
| 中国人喜欢吃火锅 | 「日本人の友達を海底撈に連れて行ったら、3時間出てこなかった。」 | 未完成的故事 |
| 留学生交朋友很难 | 「日本に3年住んで、日本人の友達は0人でした。」 | 数字冲击 |
| 日本人比较含蓄 | 「"また今度"を本気にして、3ヶ月待ってました。」 | 自曝失败 |
| 中日文化有差异 | 「日本人の彼女に、中国の"割り勘しない文化"を説明したら怒られた。」 | 未完成 + 对比 |
| 我们办了个交流会 | 「日本人と中国人を同じ部屋に入れてみた。」 | 反常识 + 悬念 |
| 敬语很难学 | 「敬語を間違えて、バイトをクビになりかけた。」 | 自曝失败 |

**规律**：把"类别名词 + 形容词"换成"一个人 + 一个动作 + 一个时间点"。抽象变具体，说明变故事。

## 钩子的画面配合

台词只占钩子的一半，另一半是画面。三秒内必须同时满足：

- **第一帧就有信息**：人脸大特写、强对比画面、或大字屏幕文字。禁止用空镜、慢摇、Logo 开场。
- **屏幕大字 = 钩子文案**：静音用户只看得到这行字，它必须能独立成立。字号占屏宽 70% 以上。
- **不留静默**：第 0 秒就开始说话或已有音乐进入，哪怕半秒的空白也会掉留存。
- **禁止片头动画**：任何品牌片头都是在烧最贵的资产。
